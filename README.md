# Sales Data Analysis with Pandas

A Python-based sales data analysis project built with **Pandas** to calculate revenue, categorize sales performance, and analyze business data across different cities and products.

## Features

- **Revenue Calculation:** Calculates total revenue based on quantity, unit price, and discount.
- **Sales Categorization:** Classifies orders into High, Medium, and Low revenue categories.
- **Best Performing Orders:** Filters orders with revenue of 1000 or higher.
- **City Performance Analysis:** Calculates total, average, and maximum revenue for each city.
- **Sales Comparison:** Uses Pivot Tables to compare product sales across different cities.
- **Data Sorting:** Ranks orders by revenue in descending order.

## Technologies Used

- Python
- Pandas

## Learning Objectives

This project demonstrates practical applications of Pandas, including DataFrames, custom functions, `apply()`, `groupby()`, aggregation, filtering, sorting, and `pivot_table()`.
